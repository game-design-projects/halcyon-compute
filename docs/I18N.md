# i18n: English + 简体中文

## Decisions
| # | Decision | Why | Rejected |
|---|---|---|---|
| I1 | One classic script `js/i18n.js` exposes `window.I18N` with `t(key, params)`, `lang`, `setLang(l)`, and `fmt` helpers. Dictionaries are plain objects `{ en: {...}, zh: {...} }`, split per area if large (`js/i18n/ui.js`, `js/i18n/content.js` …), all loaded as classic scripts before `ui.js` (they must work from `file://`, so no fetch/JSON loading). | Works from `file://` and in the itch iframe with no build step | Fetching JSON files (blocked on `file://`); an i18n library (no deps allowed) |
| I2 | The **sim stays language-neutral**. News, chapter, offer, policy and lesson text that the sim produces carries a `key` + `params` (plus the existing English `title`/`body` kept as a fallback for old saves and tests); the UI renders them through `t()`. Content data in `content.js` becomes `{ en, zh }` pairs or keys. Determinism and tests must not depend on the language. | A save made in one language opens in the other; bots and tests are unaffected | Translating inside the sim (the language would leak into state) |
| I3 | Language choice: `?lang=zh|en` > localStorage (try/catch) > `navigator.language` starting with `zh` → zh, else en. Toggle in the main menu and a small HUD button (中/EN). Switching re-renders instantly and doesn't restart the game. | — | — |
| I4 | Fonts: Barlow has no CJK glyphs. Add a CJK fallback in every font stack: `"PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Microsoft YaHei", sans-serif` (system fonts only; no web-font download for CJK, it's too large). Set `<html lang>` to match the language. | — | Loading Noto Sans SC from Google Fonts (MBs; slow in the iframe) |
| I5 | Numbers and money stay `$1.2M` / `$340k` in both languages (the game's currency notation). Dates: en `Oct 11, Y3`, zh `第3年 10月11日`. | Readable and consistent in both | Localised currency (yuan conversion would confuse the economy) |
| I6 | Every key must exist in both languages (a test enforces it). A missing key falls back to English and logs `[i18n] missing zh: key` under `?debug=1`. | — | — |

## Text diet (user feedback: "太多的文字我已经看麻了" — too much text)
Rewrite every string while translating, so **both languages come out shorter**. Show, don't tell.
- **Budgets:** chapter card = at most 3 bullets, each ≤ 8 words (en) / 12 characters (zh), each paired with an icon or a mini
  picture. Goal banner ≤ 6 words. A news item is a title only; its body moves to the tooltip. A toast is ≤ 5 words plus a number.
- **Remove standing captions** (e.g. "Drag onto a rack (or tap a card…)", the shelf and catalog explanations). Teach once with
  a pulsing hint arrow/ghost demo the first time, then never again.
- **Numbers and icons over sentences:** "−$40k · 7d" instead of "Switch to chiller: $40k, 7 days". Put detail behind hover
  (`title`) or an "ⓘ" toggle, i.e. progressive disclosure.
- The end screen keeps its lessons (they carry the learning), but each is 1 line.
- Target: count the visible words on the main screen mid-game (driver `/text`) and cut them by ≥ 50 % vs now; report the
  before/after count.

### Feedback by feel, not by text (user: "show not tell")
Replace error and status sentences with game-feel signals; keep the text only as a tiny tooltip or aria-label for accessibility.
| Situation | Signal (no sentence) |
|---|---|
| Not enough cash for a drop/buy | the cash chip shakes + flashes red; the dragged card shakes "no" and snaps back; a low "bonk" sound; the price on the card pulses red |
| Rack full (U) / over rack kW / over grid | the rack tile (or grid chip) flashes red and wobbles; the missing resource's gauge pulses |
| No switch in a rack | the rack stays dark and grey with a pulsing unplugged-cable icon; plugging in a switch plays a "power-up" light sweep |
| Throttling / too hot | heat shimmer + a red glow pulse on the rack; the heat chip pulses; the fan speeds up visually |
| Failure | spark burst + the rack LED goes red and blinks |
| Money earned / lost | floating +/− numbers (already there); a big loss = a short screen-edge red vignette |
| Bankruptcy danger | a vignette that deepens as runway shrinks; heartbeat thump sound under 30 days |
| Offer arrives / chapter unlock | an icon flies into the HUD badge with a chime; no toast sentence |
| Invalid action generally | the element shakes (translateX wobble 250 ms); never a modal |
Guard-rails: every signal is short (≤400 ms) and never blocks input; reduced-motion → colour flash only; sounds respect mute.
Shake intensity scales with severity (small wobble for a local error, a screen shake only for game-level events).
